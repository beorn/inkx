# Inline Formatting

Every row below demonstrates a single inline construct. Move the cursor over each row and verify the construct remains visually correct when under the cursor inverse.

## Bold

- plain text with **bold** word in middle
- **bold at start** of the line
- trailing **bold at end**
- **entire line is bold**
- nested **bold with _italic inside_** mix
- mixed text and **multiple bold** parts in one **line with extra**

## Italic

- plain text with _italic_ word
- _italic at start_ of line
- trailing _italic at end_
- _entire line italic_
- use _underscores too_ for italic

## Strikethrough

- a ~~struck-through~~ word in context
- ~~entire strike line~~
- trailing ~~strike at end~~
- bold and strike combined: **~~important but obsolete~~**

## Inline code

- use `foo.bar()` for method calls
- the `const` keyword is reserved
- multiple `code` spans `in one` line
- code with special chars: `a[b]` and `<div>`
- long code spans: `very_long_function_name_that_might_get_truncated(argument, another)`

## Combinations

- **bold with `code` inside**
- _italic with `code` inside_
- `code` then **bold** then _italic_ in one line
- **bold** _italic_ `code` ~~strike~~ — four in a row
