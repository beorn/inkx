# Horizontal rule styles

CommonMark accepts `---`, `***`, and `___` as horizontal rules. The
canonical serialization is `---` but the parser must accept all three.

Before dashes.

---

Before asterisks.

***

Before underscores.

___

After all three.

## Longer runs

CommonMark accepts arbitrary-length runs too:

----

Four dashes.

*****

Five asterisks.

________

Eight underscores.
