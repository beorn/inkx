# Wikilink edge cases

Paths with slashes: [[Projects/km/2026/Q1-plan]]

Paths with spaces: [[People/First Last Name]]

Paths with special characters: [[Notes/2026-01-14 — meeting]]

Paths with unicode: [[Decisions/café-naming]]

Empty alias: [[Target|]] — technically valid, unclear semantics

Whitespace in alias: [[Target|   padded]]

Nested brackets in alias are tricky: [[Target|display [with] brackets]]

Wikilink at start of line:
[[Start of line link]]

Wikilink at end of line: prose prose prose [[End of line]]

Wikilink immediately followed by punctuation: see [[Foo]], [[Bar]]; and [[Baz]].

Wikilink adjacent to another: [[A]][[B]] with no spaces.
