# /open — Open a file or directory

**Keywords**: open, finder, reveal

Open the given path in Finder (or the default app for files). No output, no listing, no commentary — just open it.

```bash
open <path>
```

If the argument is a relative path, resolve it from the repo root `/Users/beorn/Code/pim/km/`.

If no argument is given, open the current working directory.
