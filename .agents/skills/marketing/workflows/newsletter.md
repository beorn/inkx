# Newsletter Workflow

Draft and send the monthly ecosystem digest.

## Cadence

Monthly, after accumulating 3-4 published articles.

## Template

```markdown
# Silver Bulletin — {Month} {Year}

## What's New

- **[Article Title]** — One-line summary. [Read →](link)
- **[Article Title]** — One-line summary. [Read →](link)

## From the Matrix

{Pick 1-2 interesting findings from terminfo.dev}
- Ghostty 1.4 added curly underline support — see the [comparison](link)
- Only 3 terminals support Kitty graphics protocol — [full matrix](link)

## Numbers

- {X} new features tested on terminfo.dev
- silvery v{X} released with {Y}
- {Z} comparison pages now available

## Quick Links

- [terminfo.dev](https://terminfo.dev) — Terminal feature matrix
- [silvery.dev](https://silvery.dev) — React TUI framework
- [GitHub](https://github.com/beorn/silvery) — Star us!
```

## Steps

1. Gather published articles since last newsletter
2. Check terminfo.dev for new census data / interesting findings
3. Check for new releases across the ecosystem
4. Draft newsletter using template above
5. Send via Beehiiv/Buttondown
6. Update SKILL.md tracker with send date
