# Theme Explorer

Browse 84 bundled color schemes, preview how they look under Sterling, or generate a custom Theme from any color.

<ThemeExplorer />

---

Every scheme on this page feeds **Sterling**, silvery's default design system. Sterling turns the 22 slots into ~50 semantic tokens — `$fg-accent`, `$bg-surface-subtle`, `$fg-on-error`, and so on — that your components consume.

- **Learn the design system** → [Sterling guide](/guide/sterling)
- **Learn the tokens** → [Token Taxonomy](/guide/token-taxonomy)
- **Learn derivation** → [Color Schemes](/guide/color-schemes)
- **Theme API** → [`@silvery/design` reference](/reference/theme)
