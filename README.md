# Knowledge Machine

> The agentic work desk

**km** unifies your markdown files, tasks, and AI agents into one queryable system.

## Quick Start

```bash
# View tasks in any markdown directory (no setup)
km tasks

# See your knowledge tree
km tree

# Kanban board view
km board
```

## Features

**Knowledge Management**
- Treats markdown files as a unified tree of nodes
- Zero setup - works instantly on any directory
- Git-friendly plain text

**Agent Orchestration** *(coming soon)*
- Run AI agents with preconfigured harnesses
- Assign tasks to agents or yourself
- Full session logging and replay

## Install

```bash
# Clone and link locally (development)
git clone https://github.com/your-org/km
cd km
bun install
bun link
```
