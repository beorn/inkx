# [x] Color icon vs pill: only defining node gets colored icon @km/_orphan #bug #P4

Currently the color inheritance for icons and pills needs refinement:

1. **Colored icon**: Only the node that DEFINES a color (via `color=cyan` in its rules) should display a colored icon/bullet
2. **Colored pill**: Tasks that are embedded on boards (via symlink) should show a colored pill right-aligned (e.g., `@next` in cyan), where the color comes from the board's inherited color

The current implementation uses `getOwnColor()` for icon display and `getInheritedColor()` for pills, but there may be edge cases where this isn't working correctly.

Files involved:

- apps/@km/_orphan/cli/src/tui/board-pills.ts - getOwnColor(), getInheritedColor(), getBoardPills()
- apps/@km/_orphan/cli/src/tui/views/TreeNode.tsx - icon color logic
