# [x] Flexx: Add input validation to setters @km/_orphan #bug #P1

## Problem
Flexx Node setters accept invalid values silently:
- `setWidth(NaN)`, `setFlexGrow(-1)`, `setWidth(Infinity)` are accepted
- No guards against circular parent-child relationships in `insertChild()`
- Could cause silent layout corruption or stack overflow

## Location
- [node.ts:197](vendor/beorn-flexx/src/node.ts#L197) - setWidth and other setters

## Solution
Add validation:
```typescript
setWidth(value: number): void {
  if (!Number.isFinite(value) || value < 0) {
    throw new Error(`Invalid width: ${value}`);
  }
  // ...
}
```

Add cycle detection in insertChild().
