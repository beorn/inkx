# [x] Design and implement cursor API for inkx (useCursor hook) @km/_orphan #feature #P3

Ink issue #251 has been open since Dec 2019 (6+ years!) requesting cursor support.

Inkx has a unique opportunity here because:

1. useLayout() provides the position information needed
2. Ink can't solve this without layout feedback

Potential API:

- useCursor() hook that returns cursor position/control
- Explicit cursor management for text input scenarios
- Integration with focus management

This could be a major differentiator from ink.
