# [x] Implement column-to-column card move keybinding @km/_orphan #feature #P1

## Problem

Column-to-column card movement is not accessible via keybindings. The functions exist (`moveCardToColumn()`) but:

- ENTER_MOVE_MODE/CONFIRM_MOVE/CANCEL_MOVE return `beepUnimplemented()`
- SHIFT_LEFT/RIGHT are for indent/outdent, not column moves
- No command triggers moveCardToColumn() for board column shifts

## Test

Spec test exists in board.spec.ts (currently .todo):

```typescript
test.todo("node shifting (move to different column)", () => {
  const { board } = testEnv(() =>
    item(
      "board",
      item("col1", item("1a"), item("1b")),
      item("col2", item("2a")),
    ),
  );

  board.expect("#col1 #1a").toExist();
  // Need keybinding to move 1a from col1 to col2
  board.expect("#col2 #1a").toExist();
  board.expect("#col1 #1a").not.toExist();
});
```

## Implementation

Options:

1. Implement move mode (m → l/h → Enter)
2. Add new MOVE_COLUMN_LEFT/RIGHT commands
3. Use different modifier for SHIFT_LEFT/RIGHT when in board view
