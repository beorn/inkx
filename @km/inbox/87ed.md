# [x] Fix filled space bottom right of items in columns view @km/_orphan #bug #P2

When cursoring on some items in columns view, a filled space shows to the bottom right of the item.

User mentioned this appears as a 'text cursor' that turns from filled block to outline when terminal loses focus.

This is NOT a Flexx layout bug - investigation shows Flexx layout engine is working correctly for column direction layouts.

Investigation findings:
1. inkx output.ts correctly hides the cursor (CURSOR_HIDE) during rendering
2. Cursor is not explicitly shown by @km/_orphan/ink code (no CURSOR_SHOW or ?25h sequences)
3. This may be terminal-specific behavior or a cursor positioning edge case

Likely causes:
- Terminal cursor positioning issue after render
- Possible race condition where cursor is briefly visible
- May only appear in certain terminal emulators

This needs visual reproduction to investigate further. The fix may involve:
- Ensuring cursor is positioned at a known location after render
- Adding explicit cursor hide at end of render phase
- Checking if specific views don't properly overflow/clip
