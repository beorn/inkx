# [x] RepoHooks not wired up - chaos-hooks tests fail @km/_orphan #bug #P0

The chaos-hooks tests and implementation reference RepoHooks, MutationContext, and BeforeMutationResult which don't exist in repo.ts. These types were originally added as VaultHooks in commit 7d308b4 but were never properly migrated to the new Repo interface.

Tests affected:
- packages/@km/storage/tests/testing/chaos-hooks.test.ts
- packages/@km/storage/tests/testing/chaos-report.test.ts

Root cause: CreateRepoOptions doesn't have a 'hooks' option, so even if hooks are passed they are silently ignored.

Fix needed:
1. Add RepoHooks interface to repo.ts
2. Add hooks option to CreateRepoOptions
3. Wire up beforeMutation/afterMutation hooks in repo mutation methods
