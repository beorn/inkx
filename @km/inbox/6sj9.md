# [x] Replace manual dimension calculations with auto layout @km/_orphan #task #P1

The TUI has many places where dimensions are manually calculated instead of using flexbox auto layout. This causes bugs like the columns view text positioning issue.

## Places to audit and simplify:

1. ColumnsView.tsx - manual colWidth calculation
2. TreeNode.tsx - manual firstLinePadding calculation
3. layout-phase.ts - manual childTop relative position calculation
4. Any component passing explicit width prop instead of using flex

## Goal:

- Components should rely on flexbox for sizing/positioning
- Remove manual Math.floor/Math.round dimension calculations
- Use flexGrow/flexShrink instead of explicit widths where possible
- Text truncation should be handled by inkx Text wrap=truncate
