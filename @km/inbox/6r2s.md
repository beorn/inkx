# [x] Update KNode documentation - schema has drifted @km/_orphan #task #P3

## Problem

`docs/03-storage.md` documents ~12 KNode fields, but the actual implementation in `packages/km-core/src/types.ts` has 25+ fields.

### Missing from docs

- `link_to` - Target node ID for embeddings
- `link_alias` - Display alias for links
- `fs_ino` - Inode for rename detection
- `name` - Slug/identifier
- `title` - Display title
- `md_pos` - Byte offset in file
- `assigned_to` - Task assignment
- `due_date` - Due date for tasks
- `scheduled_date` - Scheduled date
- `priority` - Priority (1-5)
- `content_hash` - CAS reference for large content
- `version` - Last event ID that modified this
- `recurrence` - Recurrence pattern
- `recur_prev` - Previous recurrence instance

### Also missing

- `links` table documentation
- `meta` table documentation
- `nodes_fts` virtual table documentation

### Impact

New developers/integrations get incomplete data model understanding.
