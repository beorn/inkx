# [x] InkX: Add branded types for layout constants @km/_orphan #task #P3

The yoga-adapter now uses yoga-wasm-web's branded types (FlexDirection, Align, etc.) but the LayoutEngine interface uses plain numbers. Consider adding branded types to the LayoutConstants interface for type safety:

Current:
```typescript
interface LayoutConstants {
  FLEX_DIRECTION_ROW: number;
  FLEX_DIRECTION_COLUMN: number;
  // ...
}
```

Proposed:
```typescript
type FlexDirectionValue = number & { __brand: 'FlexDirection' };
type AlignValue = number & { __brand: 'Align' };
// ...

interface LayoutConstants {
  FLEX_DIRECTION_ROW: FlexDirectionValue;
  FLEX_DIRECTION_COLUMN: FlexDirectionValue;
  // ...
}
```

Benefits:
- Compile-time safety: can't accidentally pass ALIGN_CENTER where FLEX_DIRECTION is expected
- Better IDE autocomplete
- Self-documenting code

Trade-offs:
- More complex types
- Need to update all adapters (yoga, flexx)
- May need type assertions at boundaries
