# [x] Parser concatenates nested list content into parent @km/_orphan #bug #P1

When parsing nested markdown lists, the child list items' content gets concatenated into the parent's content field without line breaks.

Example input:
```md
- [ ] Task 1 with description
  - Subtask 1A
  - Subtask 1B
```

Expected content for Task 1: 'Task 1 with description'
Actual content for Task 1: 'Task 1 with descriptionSubtask 1ASubtask 1B'

This affects all views in the TUI since they rely on node.content for display.

Reproduction:
```bash
bun km ls -r /tmp/visual-test-repo --json | jq '.[] | select(.content | test("Task 1"))'
```

Impact: All nested list items render incorrectly in all views.
