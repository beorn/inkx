# [x] Lazy/virtualized child rendering in TreeNode @km/_orphan #feature #P2 @claude:227cdc41

World-class virtualization/truncation API for inkx via overflow props on Box.

## Final Design (validated by deep research)

```tsx
// Simple vertical scroll (virtualized under the hood)
<Box height={20} overflow='scroll'>
  {items.map(item => <Item key={item.id} />)}
</Box>

// Full options
<Box
  height={20}
  overflow='scroll'
  overflowX='hidden'
  scrollTo={selectedIndex}           // index-based (not pixels)
  onScroll={({ y, atBottom }) => {}} // atBottom for sticky behavior
  overscan={2}                       // extra items for smooth scroll
  scrollbar                          // position indicator
>
  {children}
</Box>

// Truncation with custom indicator
<Box maxHeight={5} overflow='truncate' 
     truncateIndicator={n => <Text dim>+{n} more</Text>}>
  {children}
</Box>

// Combined axes
<Box height={20} overflowY='scroll' overflowX='truncate'>
  {logLines}
</Box>

// Future: auto keyboard navigation
<Box overflow='scroll' keys>{children}</Box>
```

## Props

| Prop              | Type                                      | Description                          |
| ----------------- | ----------------------------------------- | ------------------------------------ |
| overflow          | 'visible'\|'hidden'\|'scroll'\|'truncate' | Overflow behavior                    |
| overflowX/Y       | same                                      | Per-axis override                    |
| scrollTo          | number                                    | Index to keep visible (auto-scroll)  |
| onScroll          | ({x,y,atBottom}) => void                  | Scroll position callback             |
| overscan          | number                                    | Extra items above/below viewport     |
| scrollbar         | boolean                                   | Show position indicator              |
| truncateIndicator | string\|((n)=>ReactNode)                  | '+N more' indicator                  |
| keys              | boolean                                   | (future) Auto handle arrow/pgup/pgdn |

## Key Insights

1. **scroll vs truncate are different UX contracts**
  - scroll: user CAN access all content
  - truncate: user CANNOT (needs expand action)
2. **scrollTo is index-based** (not pixels) - terminals render whole lines
3. **atBottom in onScroll** enables sticky-to-bottom for logs/chat
4. **Prior art alignment**: matches react-window, tanstack-virtual, ink-virtual-list

## Edge Cases

- Terminal resize: auto-recalc visible range
- Dynamic content: don't jump if scrolled up, stick if at bottom
- Nested scroll: outer allows inner to handle events
