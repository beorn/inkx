# [x] hightea package split: monolith → scoped packages @km/_orphan #epic #P3

Split hightea monolith into independently installable scoped packages under @silvery.

## Monorepo Layout (silvery.dev)

```
silvery/                          ← GitHub repo + `silvery` npm package
├── package.json                  ← name: "silvery" (all-in-one bundle)
├── src/index.ts                  ← re-exports @silvery/* packages
├── packages/
│   ├── react/                    ← @silvery/react (core framework)
│   ├── term/                     ← @silvery/term (terminal target)
│   ├── ansi/                     ← @silvery/ansi (chalk replacement)
│   ├── theme/                    ← @silvery/theme (design tokens)
│   ├── tea/                      ← @silvery/tea (TEA store)
│   ├── ui/                       ← @silvery/ui (component library)
│   ├── test/                     ← @silvery/test (testing utilities)
│   ├── compat/                   ← NOT published — ink/chalk compat
│   │   ├── chalk.ts
│   │   └── ink.ts
│   ├── dom/                      ← @silvery/dom (future)
│   ├── canvas/                   ← @silvery/canvas (future)
│   ├── native/                   ← @silvery/native (future)
│   ├── svelte/                   ← @silvery/svelte (future)
│   ├── vue/                      ← @silvery/vue (future)
│   ├── solid/                    ← @silvery/solid (future)
│   ├── preact/                   ← @silvery/preact (future)
│   ├── pdf/                      ← @silvery/pdf (future)
│   └── img/                      ← @silvery/img (future)
├── docs/                         ← silvery.dev site
```

## Roadmap

### Phase 1: Split + rename (from hightea)
- @silvery/react — core framework (reconciler, components, hooks, pipeline, focus)
- @silvery/term — terminal target (buffer, ANSI, protocols, run())
- @silvery/ansi — chalk replacement (already separate as @hightea/ansi)
- @silvery/theme — design tokens (from swatch, plugin-based via withTheme)
- @silvery/tea — TEA store (pure TS, optional)
- @silvery/ui — component library (shadcn-style)
- @silvery/test — testing utilities
- silvery — all-in-one bundle
- silvery/ink, silvery/chalk — compat subpaths

### Phase 2: Render targets
- @silvery/dom — browser DOM target (adapter exists)
- @silvery/canvas — HTML5 canvas target (adapter exists)
- @silvery/native — React Native target
- @silvery/pdf — PDF static render
- @silvery/img — image output (PNG/SVG)

### Phase 3: Framework engines
- @silvery/svelte — Svelte integration
- @silvery/vue — Vue integration
- @silvery/solid — SolidJS integration
- @silvery/preact — Preact integration

## Key Design Decisions

1. **@silvery/react is the core** — reconciler, components (Box, Text), hooks, pipeline, layout, focus. Target-agnostic. RenderAdapter interface for targets.

2. **@silvery/term is a target** — rendered node tree → ANSI bytes. Like react-dom to React.

3. **@silvery/theme is optional** — ColorResolver interface with default pass-through. withTheme plugin (not React context) for cross-framework compatibility.

4. **@silvery/ui depends on react + theme, NOT term** — works across all targets.

5. **@silvery/tea is standalone pure TS** — no React, no terminal deps.

6. **silvery bundle** — one import for ink+chalk replacement.

7. **Compat lives in packages/compat/** — not published separately, exported via root subpaths.
