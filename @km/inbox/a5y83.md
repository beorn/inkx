# [x] Rename .km/ignored to .km/hidden for clarity @km/_orphan #task #P3 @Bjørn Stabell

The .km/ignored file hides nodes from board view but they remain indexed in state.db. This is confusing because .kmignore (which prevents indexing entirely) sounds like the same concept.

Rename to .km/hidden to make the distinction clear:
- .kmignore = not indexed (files don't exist to km, like .gitignore)
- .km/hidden = indexed but not shown in board view (display filter)

- apps/@km/tui/src/ignored.ts → hidden.ts (rename functions: readBoardIgnored → readBoardHidden, addIgnored → addHidden, removeIgnored → removeHidden, isIgnored → isHidden)

- apps/@km/tui/src/views/Board.tsx (references)
- apps/@km/tui/src/view-navigation.ts (references)
