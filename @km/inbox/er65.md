# [x] Design TextArea component for inkx (multi-line input) @km/_orphan #feature #P3

Ink issue #676 requests multi-line input element support for chat-like applications.

Inkx could solve this better than ink because:

1. Layout-aware components know their dimensions
2. Can properly handle text wrapping and cursor positioning

Features to consider:

- Multi-line text input
- Text selection
- Edit previously entered lines
- Scrolling within the input area
