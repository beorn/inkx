# [x] Flexx: Fix flexShrink overflow calculation @km/_orphan #bug #P2

## Problem

Flexx calculates flexShrink differently than Yoga when children overflow the container.

## Expected Behavior

When children's total width exceeds container, shrink proportionally based on flexShrink values.

## Reproduction (from layout-equivalence.test.tsx)

```tsx
<Box flexDirection="row" width={20} height={3}>
  <Box width={15} flexShrink={1}>
    <Text>Shrinkable</Text>
  </Box>
  <Box width={15} flexShrink={1}>
    <Text>Also shrinks</Text>
  </Box>
</Box>
// Total child width: 30, container: 20
// Expected: Each shrinks to 10
```

## Impact

- flexShrink with overflow (row) test fails

## Investigation Points

- Check shrink calculation in `layoutNode()`
- Compare with Yoga's shrink algorithm
- Verify available space calculation

## Verification

Run: `bun test tests/layout-equivalence.test.tsx -t "flexShrink"`
After fix, unskip and verify the test passes.
