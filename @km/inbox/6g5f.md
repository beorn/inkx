# [x] O4: Plugin Composition for Keyboard Handlers @km/_orphan #task #P3

Split monolithic keyboard handlers into composable withX() plugins.

Decker pattern:

```typescript
createCoreEditor() =>
  withValidation(withReact(withCore(withStore(withOutline(base)))))
```

Proposed for KM:

```typescript
const keyboardPipeline = compose(
  withDialogHandling,
  withOutlineModeHandling,
  withCommandSystem,
  withTUISpecificKeys
);
```

Benefits:

- Easier to test individual handlers
- Clearer separation of concerns
- Easier to add new handler layers

Lower priority - current handlers work, this is refactoring.
