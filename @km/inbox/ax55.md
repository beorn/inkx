# [x] Research and plan Kitty keyboard protocol support for inkx @km/_orphan #feature #P1

Ink issue #824 and PR #852 show growing demand for Kitty keyboard protocol support. This enables:

- Differentiate shift+enter vs enter
- Differentiate ctrl+i vs tab
- Better modifier key handling
- Cross-terminal compatibility (Kitty, WezTerm, Ghostty, Alacritty)

Research needed:

1. Understand Kitty keyboard protocol spec
2. Determine how to detect terminal support at runtime
3. Design graceful fallback for unsupported terminals
4. Plan API changes (if any) to useInput()

Reference: https://github.com/vadimdemedes/ink/issues/824
