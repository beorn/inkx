# [x] inkx: Nested Text should override parent color/styles @km/_orphan #bug #P1

When nesting Text elements in inkx, child Text styles should properly override parent styles with a push/pop stack mechanism.

Example of style inheritance that should work:

```tsx
<Text color="black">
  before <Text color="red">RED</Text> after
</Text>
```

Expected: 'RED' should be red, 'after' should return to black
Actual: Current implementation applies ANSI codes but the style restoration may not work correctly for all properties.

Requirements:

1. Foreground color (color prop) - override and restore ✓
2. Background color (backgroundColor prop) - override and restore ✓
3. Bold, dim, dimColor, italic, underline, strikethrough, inverse - override and restore
4. dimColor should dim relative to parent, not absolute
5. Style stack should properly push/pop so 'after' text restores parent style

The key issue is that ANSI reset (\x1b[0m) resets ALL styles, not just the nested one. Need to either:

- Track full style state and re-apply parent styles after child
- Use SGR 22/23/24/etc to turn OFF specific attributes

Tests needed:

- Nested color override and restore
- Nested dimColor relative to parent
- Multiple levels of nesting
- Combined styles (color + bold + dim)
