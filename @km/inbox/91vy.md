# [x] Markdown serializer adds extra newlines between consecutive tasks @km/_orphan #bug #P2

## Description
The markdown serializer (`packages/km-markdown/src/nodes2md.ts`) adds extra blank lines between consecutive tasks during round-trip serialization.

## Reproduction
```typescript
const original = "- [ ] Task 1\n- [ ] Task 2";
const nodes = parseMarkdownToNodes(original, "/test.md");
const regenerated = nodesToMarkdown(nodes);
// Expected: "- [ ] Task 1\n- [ ] Task 2"
// Actual:   "- [ ] Task 1\n\n- [ ] Task 2"  // Extra newline
```

## Impact
- Content drift over time as files are edited
- Diffs show spurious changes
- May break external tools expecting consistent formatting

## Test
`packages/km-storage/tests/watch/chaos/roundtrip.test.ts` - 12 failing tests demonstrate this

## Fix Approach
Check spacing logic in `nodesToMarkdown()` - likely adding paragraph separator between all siblings instead of only between different node types.
