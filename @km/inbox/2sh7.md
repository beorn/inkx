# [x] Quick add nodes to boards with @ # + prefixes @km/_orphan #feature #P2

When viewing a board, pressing @ # or + should work like 'p' (palette/picker) but:
1. Open the same fuzzy finder interface
2. Pre-populate the input with the prefix character (@ or # or +)
3. Filter results to only show nodes matching that prefix type

This provides quick access to add specific node types:
- @ → people/contacts
- # → tags/categories  
- + → new items/quick add

The 'p' key already opens a general picker - these shortcuts are filtered variants.
