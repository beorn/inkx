# [x] Columns view: Items overwritten/truncated from top instead of bottom @km/_orphan #bug #P1

## Problem
In columns view, when there are many items AND items have multiple lines, the rendering is broken:
- Items appear to be overwritten on top of each other
- Items have their TOP lines truncated instead of bottom lines
- This is a recurring issue that has been reported 5-10 times
