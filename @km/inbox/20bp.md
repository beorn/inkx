# [x] Flexx: Fix padding+margin combined layout @km/_orphan #bug #P2

## Problem
When both padding and margin are applied, Flexx calculates the layout differently than Yoga.

## Expected Behavior
Padding on parent + margin on child should stack correctly.

## Reproduction (from layout-equivalence.test.tsx)
```tsx
<Box width={30} height={8} padding={1}>
  <Box margin={1}>
    <Text>Nested</Text>
  </Box>
</Box>
```

## Impact
- padding and margin combined test fails

## Investigation Points
- Check order of padding/margin application in `layoutNode()`
- Verify available space calculation accounts for both
- Compare with Yoga's combined spacing algorithm

## Verification
Run: `bun test tests/layout-equivalence.test.tsx -t "padding and margin"`
After fix, unskip and verify the test passes.
