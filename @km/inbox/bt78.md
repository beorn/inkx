# [x] Add MeasuredBox component to constraint system @km/_orphan #feature #P2

## Problem
Manual size estimation for scroll calculation is fragile. CardColumn uses estimatedCardHeight=3 which breaks with variable-height cards.

## Recommended Solution
Add `getItemHeight` callback to ScrollableList rather than a separate MeasuredBox component.

### API Change
```tsx
interface ScrollableListProps<T> {
  // ... existing props
  /** Get height of specific item (default: itemHeight for all) */
  getItemHeight?: (item: T, index: number) => number;
}
```

### Implementation
1. Update `calculateScrollState` to accept item heights array or callback
2. Sum actual heights instead of multiplying by constant
3. Track cumulative heights for scroll offset calculation
4. Keep backward compatible - use `itemHeight` constant when `getItemHeight` not provided

### Files to modify
- `apps/km-tui/packages/km-ink/src/constraints/ScrollableList.tsx`
- `apps/km-tui/packages/km-ink/src/views/CardColumn.tsx` (use new callback)

### Why not MeasuredBox?
Standalone MeasuredBox creates complex callback dance. Integrating height calculation into ScrollableList keeps API clean and logic centralized.
