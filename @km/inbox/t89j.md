# [x] Reorganize specs → docs: consolidate 23 files into 13+4 structure @km/_orphan #task #P2

## Goal

Rename `specs/` to `docs/` and consolidate the 23 spec files into a cleaner 13+4 structure with better narrative flow, reduced overlap, and clearer audience separation.

## Current Problems

1. **Significant overlap** - Status model defined in 4 places, bidirectional sync in 2 places, CLI commands in 3 places
2. **Fragmentation** - Tasks split across 7 files, TUI across 4 files
3. **Unclear narrative** - Reader must jump between files to understand features
4. **Audience mixing** - User docs mixed with implementation details
5. **Non-standard location** - `specs/` is less discoverable than `docs/` (GitHub convention)

## Why Rename specs/ → docs/

| Aspect | specs/ | docs/ |
