# [x] batch plugin: ast-grep backend for multi-language support @km/_orphan #task #P2 @beorn

Wire up the ast-grep backend stub to support batch renames in non-TypeScript languages.

## Languages to support
- Go, Rust, Python, Ruby (code)
- JSON, YAML (config files)

## Implementation
The backend interface already exists in `lib/backend.ts`. Need to:
1. Implement `findPatterns()` using `sg run -p --json`
2. Implement `createPatternReplaceProposal()` to generate editset
3. Register backend with lower priority than ts-morph

## ast-grep pattern syntax
```bash
# Find all function calls
sg run -p 'console.log($MSG)' --json

# Structural pattern for JSON
sg run -p '"key": $VALUE' --lang json --json
```

## Acceptance criteria
- [ ] `symbols.find --pattern X --backend ast-grep` works
- [ ] `rename.batch --pattern X --replace Y --backend ast-grep` generates editset
- [ ] `editset.apply` works with ast-grep-generated editsets
- [ ] Tests for at least Go and JSON
