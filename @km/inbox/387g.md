# [x] Replace Bun.sleep with event-based sync in tests @km/_orphan #task #P3

## Problem

4 tests use `Bun.sleep()` to wait for async operations, making them flaky:

- `packages/km-storage/tests/node-crud.test.ts:771`
- `packages/km-storage/tests/node-crud.test.ts:800`
- `packages/km-storage/tests/node-crud.test.ts:828`
- `packages/km-storage/tests/watch/reconcile.test.ts:136` (uses sleepSync)

### Impact

Tests may fail intermittently on slower systems or under load.

### Fix

Replace with event-based synchronization:

- Use Promise-based event signaling
- Wait for specific file system events instead of arbitrary timeouts
- Or use test-specific synchronization primitives
