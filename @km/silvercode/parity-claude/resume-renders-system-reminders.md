# [x] Resume renders system-reminder + command tags as raw user prompts @km/silvercode #bug #P1 @claude:2405c72e

blocks:: [[@km/silvercode]]

After --resume <sid>, replayed user messages display the entire on-disk content verbatim — including <system-reminder>, <command-name>, <command-message>, <command-args>, and <local-command-stdout> wrapper tags. The actual user-typed text is buried inside huge XML-looking blobs. Also, isMeta:true user messages (Claude Code internal metadata like 'Caveat: messages were generated by /command') leak through as if they were real user input. Symptom: scroll feels broken because messages are 100s of lines tall, contain JSON dumps, and don't render nicely. Root cause: handleUserEcho in parse.ts emits message.content verbatim when it's a string. Fix: strip wrapper tags, skip isMeta entries, render command invocations as '/cmd args'.
