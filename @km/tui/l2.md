- Board.tsx owns state via `useReducer` (TUIBoardState, UIState, BoardState)

- Interface named `BoardCapturedState_REPLACE_WITH_CREATEAPP_STORE` (flagged as temporary)
- driver.ts line 213: "WORKAROUND: Replace this driver with createApp()"

## Target
- New `apps/km-tui/src/board-app.ts` defines createApp() with Zustand store
- Board becomes pure view: `useApp(selector)` instead of useReducer

## Compatibility Issue
createApp() currently does NOT wrap with InputLayerProvider. To make L2 work while keeping useInputLayer from L1:
- Option A: Extend createApp() to accept custom providers (add InputLayerProvider)
- Option B: createApp() provides store only, key handling stays in useInputLayer
- Option C: Move InputLayerProvider inside createApp() as standard feature in inkx

Prefer Option C — InputLayerProvider should be standard in createApp().
