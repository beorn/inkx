# [x] Add backwards compatibility bridge @km/domain-objects #task #P2

Temporary compatibility layer during migration.

Old APIs delegate to a default vault singleton:

```typescript
let defaultVault: Vault | null = null;

/** @deprecated Use createVault() */
export function loadVault(path, options) {
  defaultVault = createVaultSync(path, options);
  return { mode: defaultVault.mode, ... };
}

/** @deprecated Use vault.getNode() */
export function getNode(id) {
  if (!defaultVault) throw new Error("No vault loaded");
  return defaultVault.getNode(id);
}
```

This allows incremental migration.
