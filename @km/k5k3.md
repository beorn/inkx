# [x] Zoom into node that becomes column: cursor should stay at column level, not move to card @km/k5k3 #bug #P0

When zooming into a node that becomes a column (e.g., a section node), the cursor should stay at the column level (showing the column as selected). Currently, the cursor moves to select the first card inside that column instead.

**Update:** It seems the cursor changes completely - not just moving down a level but potentially to a different column/position entirely.

Expected: After zoom, the node becomes a column and remains selected at column level
Actual: After zoom, the cursor moves to a different position (possibly first card, possibly different column)

This breaks the navigation flow - user expects to stay on the same item they zoomed into.
