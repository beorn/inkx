# [ ] Plugin and component registry for community contributions @km/silvery #task #P4

Encourage ecosystem growth by making it easy to publish and discover plugins/components:

1. **Registry format**: How plugins are listed (npm tags? GitHub topic? dedicated site?)
2. **Plugin template**: Starter template for creating a Silvery plugin
3. **Documentation**: How to write a plugin that composes cleanly (types, testing)
4. **Community seeding**: Example plugins (withVim, withEmacs, withUndo, withHistory) as templates

Ink grew via 50+ community components. BubbleTea has 100+ bubbles. Silvery needs the same flywheel.
The plugin architecture (plain functions, no framework interface) makes this easier than most frameworks.
