# [x] CI gate: verify no internal 404s after build — cmux page is 404 @km/terminfo #bug #P1

/terminals/cmux returns 404. cmux exists in terminals.json but has no probe results, so the page generator skips it. Links reference it, producing a broken link.

## Root cause chain
1. No page generated for cmux (no probes, not historical)
2. Page generator only creates pages for probed or historical terminals
3. terminals.json has entries without pages — no validation catches this
4. No build-time 404 check in CI

## Fixes needed
1. Generator: create pages for ALL terminals in terminals.json (even unprobed — show metadata without results)
2. CI: after bun run build, crawl all internal links and verify no 404s
3. Sitemap: only include pages that actually exist

## CI 404 check implementation
After vitepress build, scan all .html files for internal links, verify each target exists:
```bash
# In .github/workflows/docs.yml, after build step:
bun scripts/check-internal-links.ts docs/.vitepress/dist/
```
