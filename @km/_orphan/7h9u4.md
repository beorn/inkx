# [x] Heartbeat interval never cleared in tui.tsx — resource leak @km/_orphan #bug #P2 @claude:8f007ba9

In tui.tsx runBoard(), setInterval(200ms) heartbeat monitor is created but never cleared. If runBoard is called multiple times (testing, re-entry), each invocation leaks a timer. The void cast suppresses the unused variable warning, masking the leak. Fix: clearInterval in cleanup path alongside syncManager.stop().
