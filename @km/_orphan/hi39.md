# [x] inkx: ANSI regex misses extended SGR codes and OSC 8 @km/_orphan #bug #P0

Critical: vendor/beorn-inkx/src/unicode.ts:543 uses /\x1b\[[0-9;]*[A-Za-z]/g which fails to strip extended SGR codes (underline color \x1b[4:3m) and OSC 8 hyperlinks. Should use /\x1b\[[0-9;:]*m|\x1b\]8;;[^\x1b]*\x1b\\/g like chalkx.
