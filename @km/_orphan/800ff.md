# [x] termless: session creation leaks PTYs/backends on failure @km/_orphan #bug #P1 @claude:c9beade3

Found by GPT 5.4 Pro review (2026-03-13).

File: packages/cli/src/session.ts:53-82
Classification: P1

If spawn(), waitForStable(), waitFor(), or waitForContent() throws before sessions.set(), the terminal is never tracked and not cleaned up by stopAll().

Suggested fix: Wrap session creation in try/catch; on failure, await terminal.close() before rethrowing.
