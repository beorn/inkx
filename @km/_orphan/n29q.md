# [x] InkX: Navigation into empty column and back fails @km/_orphan #bug #P2

In Columns and Kanban views, navigating into an empty column (one with no cards) and then trying to navigate back out doesn't work correctly. The cursor may get stuck or the navigation state may become inconsistent. This affects keyboard navigation (h/l or arrow keys) when columns have varying card counts.
